# 🚀 3D Portfolio

A stunning, interactive 3D portfolio built with **React**, **Three.js**, and **React Three Fiber** — featuring smooth animations, a modern dark theme, and immersive 3D elements.

## 🌐 Live Demo

**[View Live Site →](https://threed-portfolio-w2rz.onrender.com)**

## 🛠 Tech Stack

- **React 19** — UI framework
- **Three.js + React Three Fiber** — 3D rendering
- **Drei** — Useful Three.js helpers
- **Vite** — Build tool
- **Oxlint** — Linting

## ✨ Features

- Interactive 3D scene with floating geometry and particles
- Smooth scroll animations
- Responsive design
- Dark theme with modern UI
- Sections: Hero, About, Projects, Skills, Contact, Footer

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/tanishq1983/portfolio-.git
cd portfolio-

# Install dependencies
npm install

# Start dev server
npm run dev
```

## 📦 Build & Deploy

```bash
# Build for production
npm run build

# Preview production build
npm run preview
```

This project is auto-deployed to [Render](https://render.com) on every push to `main`.
